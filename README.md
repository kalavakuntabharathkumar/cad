# Clinic Appointment Dashboard — Design-to-Code Frontend

Responsive React/Vite clinic appointment UI inspired by a Figma-to-code workflow. Includes dashboard summary cards, appointments list, search, status filtering, responsive layouts, reusable components, and React Context + useReducer state management.

## Requirements
- Node.js 18+ and npm

## Run on Windows PowerShell
```powershell
npm install
npm run dev
```
Open the local URL printed by Vite.

## Build
```powershell
npm run build
```

## Notes
This is a front-end demo using in-memory sample appointments. It does not connect to a real clinic system or backend. Replace sample data and add authentication/API integration before production use. Resume metrics such as 24 mockups, defect reductions, line counts, user counts, and collaboration figures are not claimed as measured by this starter project.
